# Task Management — Learning Docs

This folder is your personal reference for everything built in this project.
Each block has its own file explaining **what was built**, **why**, and **the concepts behind it**.

---

## Structure

```
docs/
├── README.md                          ← You are here
├── progress/
│   ├── MASTER_TODO.md                 ← Single source of truth for all TODOs
│   └── BLOCK_STATUS.md                ← Quick overview of what is done / in progress
└── blocks/
    ├── Block1-Domain-Layer.html       ← Clean Architecture + Domain concepts     [AR/EN]
    ├── Block2-Application-Layer.html  ← Use Cases, DTOs, Service Interfaces      [AR/EN]
    ├── Block3-Infrastructure.html     ← EF Core, SQL Server, Repositories        [AR/EN]
    ├── Block4-Auth.html               ← JWT, Password Hashing, Security          [AR/EN]
    ├── Block5-API-Controllers.html    ← Controllers, Routing, Authorization      [AR/EN]
    ├── Block6-Redis-Caching.html      ← Redis, Cache Invalidation                [AR/EN]
    └── Block7-Background-Jobs.html    ← BackgroundService, Channels, Queue       [AR/EN]
```

---

## How to Use

- Check `progress/MASTER_TODO.md` for your current tasks
- After finishing a block, **open the matching `.html` file in your browser**
- Lessons are written in **Arabic** with English code blocks and technical terms
- Each file has: What was built, Lessons with explanations, Common mistakes table
